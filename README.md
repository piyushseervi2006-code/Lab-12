# LAB-12 – Business Cart Online Shopping Website

## About the Project

Business Cart is a modern online shopping website developed using HTML, CSS, JavaScript and XML as part of the Web Technology Laboratory.

The website allows users to explore products, view product details, add items to a shopping cart and complete a sample checkout process.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- XML

## Website Pages

1. Home Page
2. Products Page
3. Product Details Page
4. Shopping Cart Page
5. Checkout Page
6. Login Page
7. Registration Page
8. Contact Page

## Features

- Modern and responsive website design.
- Product information stored in XML.
- Dynamic product display using JavaScript.
- Featured products and product categories.
- Individual product details.
- Add products to shopping cart.
- Update product quantities.
- Remove products from cart.
- Automatic total price calculation.
- Login and registration demonstration.
- Sample checkout and order confirmation.
- Contact form.
- Shopping cart data saved using browser localStorage.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click and select **Open with Live Server**.
5. Explore the different pages of Business Cart.

## Learning Outcomes

- Understanding HTML webpage development.
- Applying CSS for website styling.
- Implementing JavaScript functionality.
- Understanding XML data and parsing.
- Learning shopping cart operations.
- Using browser localStorage.
- Developing a responsive shopping website.
